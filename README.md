# bharti-harsh

Royal Digital Wedding Invitation for **Harsh Wadhera & Bharti Sharma**.

### Features
- 3D Interactive Royal Gate Opening with embossed HB crimson wax seal
- Moonlit palace courtyard hero scene with gold calligraphy
- Sacred traditional Sanskrit shloka & family blessings
- Interactive scratch-to-reveal gold heart card for wedding date (24 November 2026) with celebratory confetti burst
- Live countdown timer
- Wedding events timeline with direct Google Maps buttons:
  - Wedding Ceremony at **Radisson Blu Hotel, New Delhi Dwarka**
  - Grand Reception at **Mystique Banquet, New Delhi**
- Interactive guest RSVP form
- Soothing background instrumental audio toggle with rotating vinyl record player

### Run Locally
```bash
npm install
npm run dev
```

### Deploy on Vercel
Import this repository directly into Vercel and deploy.
